# 📌 Project 4: Loan Approval Prediction System
### Python Scikit-Learn Status

## 🌟 Project Overview
The **Loan Approval Prediction System** is a Machine Learning classification project. The goal of this system is to evaluate applicant financial profiles, employment statuses, and demographic information to accurately predict whether a loan application will be approved or rejected.

## 🎯 Project Objectives
* Improve data analysis and preprocessing techniques.
* Apply machine learning classification algorithms to real-world financial data.
* Evaluate and compare multiple models using industry-standard performance metrics.
* Build functional predictive models to streamline banking decision-making.

## ⚙️ Features & Workflow
* **Dataset Management:** Utilizes applicant datasets containing records such as gender, marital status, education, income, loan amount, and credit history.
* **Data Cleaning & Preprocessing:** Handles missing values, removes duplicates, encodes categorical variables, and performs feature scaling.
* **Exploratory Data Analysis (EDA):** Analyzes trends, approval rates, and statistical distributions to uncover key insights.
* **Model Training & Testing:** Splits data and trains three distinct machine learning classifiers:
  * Logistic Regression
  * Decision Tree Classifier
  * Random Forest Classifier
* **Performance Evaluation:** Assesses results using Accuracy Score, Precision, Recall, F1 Score, and Confusion Matrices.

## 🛠️ Technologies & Tools Allowed
* **Programming Language:** Python
* **Data Manipulation & Processing:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning Framework:** Scikit-learn
* **Development Environment:** Jupyter Notebook / Google Colab

## 📊 Model Performance Summary
Based on rigorous evaluation metrics, the **Random Forest Classifier** achieved the highest accuracy and overall predictive performance:

| Model | Accuracy | Precision | Recall | F1 Score |
| :--- | :---: | :---: | :---: | :---: |
| **Logistic Regression** | 0.8049 | 0.8427 | 0.8824 | 0.8621 |
| **Decision Tree Classifier** | 0.8211 | 0.8462 | 0.9059 | 0.8750 |
| **Random Forest Classifier** | 0.8618 | 0.8542 | 0.9647 | 0.9061 |
